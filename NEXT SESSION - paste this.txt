**On the 54 worksheet replies — the only surface Phase 4 renders on — 72 candidates, 40 of them

1. **A shouted word is not evidence.** `SEND` in 56 replies and `EAL` in 53, plus `HARD`, `SOFT`,

2. **A spaced dash and a pipe end a segment.** *"Hook - What is a rock?"*, *"Rock name |

3. **A run followed by a number is furniture.** `Step 3`, `Year 3`, `Activity 1`, `Lesson 1`.

4. **The subject is hers**, derived from `SUBJECT_REGISTRY` — `English` alone was in 47 replies.
5. 🔑 **A vetoed heading may not vouch for the word it capitalised.** This was the single largest

   very headings the title-case veto had just thrown out. `Hook`, `Plenary`, `Practice`,
   `Modelling`, `Is`, `Hard`, `Smooth`, `Soft` all died with this one line.
6. **A run of nothing but English function words names nothing.** 🔑 **This is the one list in

   right that the words opening an instruction cannot be enumerated; articles, pronouns,
   auxiliaries, interrogatives, conjunctions and quantifiers are the opposite.

⚠️ **`is` was in the minor-word set and that was a false PASS.** Title case capitalises verbs, so
*"Who is Alice?"* read as a heading and was vetoed whole — a comprehension question about a name

- **`pages_in(filename, data)`** — page count, or `None` for anything that is not a PDF **and for

  per file, because a rerun must not wipe what she typed beside it. Widget keys carry the file, so
  swapping a long PDF for a short one cannot leave a page number the new file does not have.

  built from that file alone: without it the app does not start at all, with it everything loads.

`AppTest.from_function` runs the panel's PDF path as a real script with a stand-in upload, sets the
page numbers the way she would, and reads back the base64 that would travel. **The AST tests could

**The spec it was built from, kept for its reasoning:**

🚨 **THE DEFECT IT CLOSED, AS IT READ BEFORE THE BUILD.** If she uploads a PDF the
worksheet screen sends **the whole file** to Claude — `blocks_for_upload` (`planning/scheme_intake.py:134`)
base64s the entire document into one `document` block, and nothing narrows it. So a chapter scan

scan is also the one route where the Phase 4 name check cannot run. Pasted and Word text are fine —
she edits the box, and the names are checked. **The scan route is her main English route.**

**Why a page picker and not a bigger check.** It fixes the constraint at the source: send only the
pages the children have reached and the app *cannot* reveal what comes later. 🚨 **DO NOT implement
this by telling the model "only use pages 4 to 6" in the prompt.** That is exactly the shape the
adversarial pass killed — her one hard constraint defended by a sentence at the end of a prompt.
The bytes must not leave the machine.

**Scope: PDFs only.** A `.docx`, `.txt`, `.md` or paste lands in the editable box, which she can
already cut down by hand. A photograph is a single page, and the uploader takes one file at a time
(`st.file_uploader` with no `accept_multiple_files`), so there is nothing to choose between.

**The shape to build:**

- **`pypdf`** — cutting a PDF to a page range is structural and works on a scan, which has no text
  layer to read. ⚠️ **Measured 2026-09-21: `pypdf` is NOT installed and NOT a transitive dependency**
  (checked against the interpreter, and `requirements.txt` is four lines: streamlit, python-docx,
  anthropic, python-dotenv). It is pure Python with no compilation, so it is safe for the hosted

- **TDD genuinely.** Failing test first, confirm it fails FOR THE REASON YOU EXPECT, then

- **A test cannot see a prompt defect.** Fifteen of fifteen defects in this repo were found only

  nothing about one. When the thing you changed only fires on failure, cause the failure.
- **The artefacts are a corpus, not a receipt.** `scripts/sweep_refusals.py` and

  guard, not after.

  error message from three different causes.
- **A guard that refuses correct work is worse than no guard** — invisible on a green suite, and
  it surfaces as the teacher being told her correct work is wrong. But make a wrong guard RIGHT,
  never soften it. ⚠️ And a guard can be wrong by being too LOOSE, which is worse: a refusal is
  visible and gets a second attempt, while a false pass hands a child a sheet that proves nothing.
- **A refusal the model will read is an instruction, not a description.**
- **Deterministic checks only. No AI judging AI.**

  this app calls is `claude-haiku-4-5-20251001`, its ceiling is 64,000 output tokens, and a reply
  above roughly 16,000 must be streamed or the server closes the connection — which is what
  happened here on 2026-09-02. `MAX_REPLY_TOKENS` is 16,384 for that reason, not the model's
  ceiling.
- **`app.py` stays structurally untouched.** No refactor. It has almost no coverage and it works.
